# Expense Tracker

A web-based Expense Tracker built using Flask and SQLite that helps users record, manage, and analyze their daily expenses through an easy-to-use dashboard.

## Features

✅ Add new expenses

✅ View and manage all expenses

✅ Delete expenses

✅ User profile management

✅ Monthly expense tracking

✅ Category-wise expense analysis

✅ Interactive dashboard with visual reports

✅ SQLite database integration

## Tech Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2 Templates

## Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/expense-tracker.git
cd expense-tracker
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install flask
```

## Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
